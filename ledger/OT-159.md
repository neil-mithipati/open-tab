## What

Nothing blocks a user at the code level — build, 653/653 tests, lint, and
`npm run check:drift` against the live project are all clean. What blocks them
is that the app cannot reach production at all.

Three findings, in order:

1. **`vercel.json` was invalid JSON** — missing comma after the `crons` array.
   Vercel rejects the file and fails the deployment before it builds. Committed
   broken in `f575cf3`. **Fixed in the main checkout, uncommitted at the time
   this task was filed** — verify it is committed before doing anything else.
   The daily `/api/cron/purge-receipt-images` cron is declared in this same
   file, so it never registered either.

2. **`"git": { "deploymentEnabled": false }`** — git-push deploys are off.
   Deliberate in `f575cf3` ("disable auto-deploy in Vercel"). Owner decision
   whether to flip it or keep deploying by hand with `npx vercel --prod`. Do
   not flip it without the owner saying so.

3. **No `.vercel` link in this checkout** — nothing here has ever deployed.
   Linking is an owner step (`npx vercel`), not an agent step.

## Env vars that must be set in the Vercel project before first deploy

Read out of the code, not guessed — `grep -rho 'process\.env\.[A-Z0-9_]*' src`:

- `NEXT_PUBLIC_APP_URL` — **highest risk.** `src/lib/qr/inviteUrl.ts:8` throws
  `"NEXT_PUBLIC_APP_URL must be set in production"` when unset and
  `NODE_ENV === "production"`. Every share link and QR code goes through
  `buildTabUrl`, so the whole crowd-claim flow is dead without it. Covered in
  `docs/deployment.md:189`.
- `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` — read by
  `src/proxy.ts` on every matched request.
- `SUPABASE_SECRET_KEY` — service client, used by the no-login claim actions.
- `GOOGLE_AI_API_KEY` — receipt parsing.
- `CRON_SECRET` — `src/app/api/cron/purge-receipt-images/route.ts:67` refuses to
  run without it. Owner generated one 2026-08-20 per `docs/kanban.md:46`;
  confirm it is in the Vercel project, not only in `.env.local`.
- `RECEIPT_IMAGE_RETENTION_DAYS` — owner set to 14 on 2026-08-20, same note.

An agent cannot read or set any of these. This half is an owner checklist;
the task's code scope is `vercel.json` and the `docs/deployment.md` section.
